Para esta clase nos hemos descargado un fichero .jar correspondiente a la base de datos H2.
Para descargar este fichero, hay que ir alsiguiente enlace:

* https://www.h2database.com/html/download.html 

Este .jar lo guardaremos en una carpeta que se llame lib, por ejemplo puede estar situado así:

```
Proyecto_Ficheros/
 ├─ lib/
 │   ├─ json-20240303.jar (este es el fichero de la clase 2)
 │   └─ h2-2.2.224.jar
 ├─ Clase_01/
 ├─ Clase_02/
 ├─ Clase_03/
 ├─ Clase_04/
 └─ Clase_05/
```

Por otro lado, el fichero InitBDJuegos.java no se ha explicado en clase. Su única finalidad es que lo ejecutéis para que realice una pequeña inserción en una tabla de vuestra base de datos.

De esta forma, si queréis comprobar el resultado en el explorador, podéis acceder a http://localhost:8082 y visualizar dicha inserción.
