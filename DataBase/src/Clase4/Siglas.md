| Sigla / Término                   | Significado (en inglés)                             | Traducción / Explicación                                                                                                   |
| --------------------------------- | --------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| **SGBD**                          | *Sistema de Gestión de Bases de Datos*              | Software que permite crear, administrar y consultar bases de datos (MySQL, Oracle, PostgreSQL…).                           |
| **SGBDR**                         | *Sistema de Gestión de Bases de Datos Relacionales* | SGBD basado en el modelo relacional, que organiza los datos en tablas con relaciones entre ellas.                          |
| **SQL**                           | *Structured Query Language*                         | Lenguaje estándar para consultar y manipular bases de datos relacionales.                                                  |
| **ODBC**                          | *Open Database Connectivity*                        | Estándar creado por Microsoft que permite conectar aplicaciones con distintas bases de datos mediante un driver genérico.  |
| **JDBC**                          | *Java Database Connectivity*                        | API de Java que permite a los programas Java conectarse y comunicarse con bases de datos relacionales usando SQL.          |
| **API**                           | *Application Programming Interface*                 | Conjunto de clases, métodos e interfaces que permiten a los programadores interactuar con un sistema o biblioteca.         |
| **Driver JDBC**                   | —                                                   | Componente (programa) que traduce las órdenes JDBC al formato que entiende un SGBD concreto (por ejemplo, MySQL, Oracle…). |
| **DriverManager**                 | —                                                   | Clase de la API JDBC que gestiona los controladores disponibles y establece conexiones con las bases de datos.             |
| **Connection**                    | —                                                   | Objeto que representa una conexión activa con la base de datos.                                                            |
| **Statement / PreparedStatement** | —                                                   | Objetos usados para ejecutar sentencias SQL sobre una conexión JDBC.                                                       |
| **ResultSet**                     | —                                                   | Objeto que contiene los resultados devueltos por una consulta SQL (`SELECT`).                                              |
| **Tipo I JDBC**                   | *JDBC-ODBC Bridge Driver*                           | Usa ODBC como intermediario. En desuso.                                                                                    |
| **Tipo II JDBC**                  | *Native API Driver*                                 | Usa bibliotecas del sistema operativo.                                                                                     |
| **Tipo III JDBC**                 | *Network Protocol Driver*                           | Usa un protocolo intermedio entre Java y la BD.                                                                            |
| **Tipo IV JDBC**                  | *Pure Java Driver*                                  | Driver 100% Java. Se conecta directamente a la base de datos. Es el más usado hoy.                                         |
| **BD Embebida**                   | *Embedded Database*                                 | Base de datos que funciona dentro de la aplicación (sin servidor independiente). Ejemplos: SQLite, H2, ObjectDB.           |
| **H2**                            | —                                                   | Base de datos embebida escrita totalmente en Java. Muy usada para pruebas y desarrollo.                                    |
| **SQLite**                        | —                                                   | Base de datos relacional ligera que guarda todo en un único archivo. Ideal para aplicaciones locales o móviles.            |
| **ObjectDB**                      | —                                                   | Base de datos embebida orientada a objetos, sin necesidad de SQL. Guarda directamente instancias de clases Java.           |
